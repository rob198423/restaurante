# Ouvido Perfeito BR

Aplicativo web em português para treino auditivo, transcrição de melodias,
fraseado musical e técnicas de guitarra com áudio gerado no navegador.

## Recursos

- Reconhecimento de intervalos melódicos.
- Ditado melódico por graus da escala maior.
- Reconhecimento de ideias de fraseado.
- Laboratório tonal com drone, escala e controle de andamento.
- Método guiado para tirar melodias de músicas.
- Técnicas de guitarra para improviso: pedal point, sequências, aproximações
  cromáticas e motivos rítmicos.

## Como executar

Abra `index.html` diretamente no navegador ou sirva a pasta com:

```bash
python3 -m http.server 4173
```

Depois acesse `http://localhost:4173`.
